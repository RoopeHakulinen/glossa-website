The path to C1

Eight tiers, one clear route from first words to advanced.

Each tier is a set of modules on one level. Take the modules in any order; the next tier opens when you have passed every module exam in the one before. If you already know some of the language, a placement test built from the module exams can start you at a later tier. After that nothing is skipped, so what you learn later rests on what you already know.
