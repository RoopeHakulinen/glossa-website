# glossa.study website

A static site for https://glossa.study. The app itself is served at https://app.glossa.study, which is also where the legal and support pages live. `CNAME` names the custom domain for static hosts that use it, such as GitHub Pages.

The pages exist in English (the site root), German (`de/`), Spanish (`es/`), French (`fr/`), Italian (`it/`), Brazilian Portuguese (`pt/`), Finnish (`fi/`), Russian (`ru/`) and Ukrainian (`uk/`), the languages of the app's interface. A change to a page's text belongs in all nine versions. The language menu in each header and the `hreflang` links in each `<head>` point to the same page in the other languages. Module lists of courses taught in English stay in English on every version, because they show the course's own titles.

The course and exam pages under `exams/` and `courses/` (and their language folders) are generated by `tools/landing-pages/build.mjs` from JSON; edit the JSON and run the script, never the HTML. They exist only in the languages of the learners each page is for, not in all nine; `tools/landing-pages/README.md` explains the format. The script also writes `sitemap.xml`.
