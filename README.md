# glossa.study website

A static site for https://glossa.study. The app itself is served at https://app.glossa.study, which is also where the legal and support pages live. `CNAME` names the custom domain for static hosts that use it, such as GitHub Pages.

The pages exist in English (the site root), Russian (`ru/`) and Spanish (`es/`), the languages of the app's interface. A change to a page's text belongs in all three versions. The language menu in each header and the `hreflang` links in each `<head>` point to the same page in the other languages. Module lists of courses taught in English stay in English on every version, because they show the course's own titles.
